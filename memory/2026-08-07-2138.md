## 二、修正后的 WSL2 智能代理配置（已写入 ~/.bashrc）

```bash
# Windows 变色龙加速器 - 智能代理配置
# 自动检测代理是否可用，不可用时自动禁用
__check_chameleon_proxy() {
    local PROXY_HOST="127.0.0.1"
    local PROXY_PORT="1234"
    local TIMEOUT=2
    # 使用 timeout 和 bash 内置的 /dev/tcp 检测端口是否开放
    if timeout $TIMEOUT bash -c "echo > /dev/tcp/$PROXY_HOST/$PROXY_PORT" 2>/dev/null; then
        # 代理可用，设置代理环境变量
        # 2026-08-07 实测：变色龙是 SOCKS5 代理（HTTP CONNECT 隧道挂起），
        # 必须用 socks5:// 协议，git 用 -c http.proxy=socks5://127.0.0.1:1234 7秒完成 fetch
        export http_proxy="socks5://$PROXY_HOST:$PROXY_PORT"
        export https_proxy="socks5://$PROXY_HOST:$PROXY_PORT"
        export HTTP_PROXY="socks5://$PROXY_HOST:$PROXY_PORT"
        export HTTPS_PROXY="socks5://$PROXY_HOST:$PROXY_PORT"
        export all_proxy="socks5://$PROXY_HOST:$PROXY_PORT"
        export ALL_PROXY="socks5://$PROXY_HOST:$PROXY_PORT"
        export no_proxy="localhost,127.0.0.1,::1"
        export NO_PROXY="localhost,127.0.0.1,::1"
        echo -e "\033[32m✅ 变色龙代理已启用 (SOCKS5 127.0.0.1:$PROXY_PORT)\033[0m"
    else
        # 代理不可用，清除代理环境变量
        unset http_proxy https_proxy HTTP_PROXY HTTPS_PROXY no_proxy NO_PROXY
        unset all_proxy ALL_PROXY
        echo -e "\033[33m⚠️ 变色龙未运行，使用直连模式\033[0m"
    fi
}
# 在交互式 shell 启动时自动检测
__check_chameleon_proxy
```

## 三、各工具使用方式

### 1. Git（最常用，重点修正）
```bash
# ✅ 正确（SOCKS5）— 7 秒完成

git -c http.proxy=socks5://127.0.0.1:1234 -c https.proxy=socks5://127.0.0.1:1234 pull
git -c http.proxy=socks5://127.0.0.1:1234 -c https.proxy=socks5://127.0.0.1:1234 clone https://github.com/xxx/yyy.git

# ❌ 错误（HTTP）— 会挂起/失败
git -c http.proxy=http://127.0.0.1:1234 fetch origin   # GnuTLS recv error / 无限挂起
```

### 2. curl
```bash
# ✅ SOCKS5（推荐 --socks5-hostname，代理做 DNS 防泄漏）
curl --socks5-hostname 127.0.0.1:1234 https://api.github.com

# ❌ HTTP 代理方式 — 会挂起
curl -x http://127.0.0.1:1234 https://api.github.com
```
